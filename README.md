# ✅ To-Do List App

A task management app built with **Python** and **Streamlit**.

## ✨ Features
- ➕ Add tasks with priority, category and due date
- 🔴🟡🟢 High, Medium, Low priority levels
- 📂 Categories — Work, Study, Personal, Health, Shopping
- ✅ Mark tasks as complete
- 🗑️ Delete individual tasks
- 🔍 Search and filter tasks
- 📊 Summary — Total, Completed, Pending
- ⬇️ Export all tasks as CSV file
- 🗑️ Clear all tasks at once

## 🛠️ How to Run
pip install -r requirements.txt
streamlit run todo.py
